# 量子ビット群衆ランナー

「+5」「×2」のゲートで群衆を増やす広告系ランナーを、量子ビットに置き換えたブラウザゲームの試作です。

- 群衆 60 人は一人ひとりが純粋状態の量子ビット。群衆平均が密度行列 ρ（ブロッホベクトル r）になります。
- 左右のレーンを選んで量子ゲート（X, Y, Z, H, S, T, Rx …）をくぐり、磁場（歳差）・位相ノイズ（T2）・減衰（T1）ゾーンを抜けます。
- 終点のボスが指定する軸で全員を射影測定し、+n に出た人数が HP 以上ならクリア。

## 遊び方

`index.html` をブラウザで開くだけです（ビルド不要）。

- ← → キー、A / D、または画面の左右タップでレーン変更
- ステージ 1〜4：反転 / 位相合わせ / スピンエコー / 観測の誘惑

## 構成

| パス | 内容 |
| --- | --- |
| `src/qcore.js` | スピノル演算、ゲート、ノイズ（量子軌道法）、測定、スコア |
| `src/levels.js` | ステージ定義（ゲート位置、ゾーン、ボス） |
| `src/game.js` | Canvas 2D 描画（道路 + ブロッホ球）とゲームループ |
| `tests/check_levels.js` | 全レーン選択を総当たりし、正解ルートだけが HP を超えるか検証 |
| `build.py` | 単一ファイル版 `dist/index.html` を生成 |

## 物理モデル

- ゲート：軸 n まわりの回転 U = cos(θ/2) I − i sin(θ/2) n·σ
- 歳差：Rz(ω_i ds)。ω_i は人ごとに固定のばらつき（不均一幅 → T2*、スピンエコーで回復可能）
- 位相緩和：ランダム Rz キック（分散 2γ ds）。群衆平均の非対角成分が e^{−γ s} で減衰
- 振幅減衰：確率 γ|β|² ds で |0⟩ へジャンプ、それ以外は β を e^{−γ ds/2} 倍して規格化
- ボス：P(+n) = (1 + r_i·n)/2 で各人を測定。スコア = 攻撃人数 × 100 + round(1000 × (1 + r·n)/2)

## 開発

```sh
node tests/check_levels.js   # ステージ難易度チェック
python3 build.py             # dist/index.html を生成
```
