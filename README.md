# 量子ビット群衆ランナー

「+5」「×2」のゲートで群衆を増やす広告系ランナーを、量子ビットに置き換えたブラウザゲームの試作です。

- 群衆 60 人は一人ひとりが純粋状態の量子ビット。群衆平均が密度行列 ρ（ブロッホベクトル r）になります。
- 左右のレーンを選んで量子ゲート（X, Y, Z, H, S, T, Rx …）をくぐり、磁場（歳差）・位相ノイズ（T2）・減衰（T1）ゾーンを抜けます。
- 終点のボスが指定する軸で全員を射影測定し、ダメージ = 当たり（+n）− はずれ（−n）が必要ダメージ以上ならクリア。超えた分はスコアと通貨「ケット」になります。
- 「+10人」「−10人」「×2（CNOT コピー）」で人数が増減します。×2 は縦の成分しか写せない（複製不可能定理）ので、横向きのときに取ると罠です。
- ケットでスキン（群衆の見た目）を買ったり、ステージをスキップしたりできます。

## 遊び方

`index.html` をブラウザで開くだけです（ビルド不要）。

- ← → キー、A / D、または画面の左右タップでレーン変更
- 3 章 15 ステージ。前のステージをクリア（またはスキップ）すると次が開放されます。次元を 1 つずつ増やして慣れていく構成です。
  - 第1章 数直線（1D）：z 軸上の確率ビット。X、減衰、ビット反転
  - 第2章 円（2D, XZ 面）：数直線が縦の直径に。H、Z、Y、Ry、位相ノイズ
  - 第3章 球（3D）：S、T、磁場（歳差）、スピンエコー、観測
- 各ステージの前に「はじめて出てくるゲート・ゾーン」の説明が出ます

## 物理モデル

- 一人ひとりはブロッホベクトル r_i（|r_i| ≤ 1、混合状態も可）。1 次元章は r_i = (0,0,z)、2 次元章は (x,0,z) に留まるゲートとノイズだけを使う
- ゲート：軸 n まわりの回転 U = cos(θ/2) I − i sin(θ/2) n·σ
- 歳差：Rz(ω_i ds)。ω_i は人ごとに固定のばらつき（不均一幅 → T2*、スピンエコーで回復可能）
- 位相緩和：3D はランダム Rz キック（分散 2γ ds）、2D は一人ずつ横成分を e^{−γ ds} 倍（面から出さないため）。どちらも群衆平均の横成分は e^{−γ s} で減衰
- 振幅減衰：z → 1 − (1 − z)e^{−γ ds}、横成分 × e^{−γ ds/2}
- ビット反転：確率 γ ds で X（平均の z は e^{−2γ s} で減衰）
- +10人：|0⟩ の新しい量子ビットを用意して合流。−10人：ランダムに消失
- ×2（CNOT コピー）：|0⟩ の新人を標的に CNOT。本人・コピーとも r → (0, 0, z)。本来は二人の z 測定結果が完全相関するが、期待値は同じなので独立に扱っている
- ボス：P(+n) = (1 + r_i·n)/2 で各人を測定。ダメージ = Σ ±1（期待値 Σ r_i·n）。「人数を増やしたが向きがそろっていない」群衆は期待ダメージ 0 になる
- スコア = ダメージ × 100 + round(1000 × (1 + r·n)/2)。ケット = クリアで 20 + 超過ダメージ × 2
